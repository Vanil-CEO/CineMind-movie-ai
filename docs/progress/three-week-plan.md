# CineMind - 3-Week Development Plan

## Week 1: Project Idea and Requirements

Goal: define the app concept, target users, system roles, and main features.

Planned work:

- Choose the project topic: CineMind movie recommendation app.
- Describe the goal of the mobile application.
- Define the main user roles: user, administrator, AI/recommendation service, API/database.
- List the main user actions.
- Prepare the first project description for practical work.

## Week 2: Application Structure and UI Planning

Goal: prepare the app structure and decide how the main screens should work.

Planned work:

- Choose Flutter as the implementation technology.
- Plan the main screens: login, preferences, home, movie details, favorites, AI assistant, admin panel.
- Prepare local demo data for movies.
- Decide how recommendations will be calculated in the prototype.
- Prepare the base project structure for further implementation.

## Week 3: Flutter Prototype and Report

Goal: create a working prototype and document progress.

Planned work:

- Create the Flutter project.
- Implement the main screens and navigation.
- Add local movie data and recommendation logic.
- Add favorites, rating, AI assistant prototype, and admin catalog management.
- Generate screenshots of progress.
- Prepare the Week 3 Word report.
- Publish the project to GitHub with visible progress documentation.
